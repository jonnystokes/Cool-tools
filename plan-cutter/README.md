# Plan Cutter

Draw a crooked room, place sheet material (4×8 foam, drywall, plywood …) on a ceiling or wall, cut it
along the walls and cabinets, and print the numbers to mark on the real board.

Open it: https://jonnystokes.github.io/Cool-tools/plan-cutter/

Your work stays in your browser's storage; export and import files to move it.

The source lives in Jon's `Projects\plan-cutter` folder (built with `python build.py`, which also writes
this page); this folder holds only the finished page.
