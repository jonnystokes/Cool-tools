`jonnystokes/Cool-tools` was renamed `cooltools`). GitHub Pages does not forward a renamed repository's site, so
this repository keeps the old address alive: GitHub Pages serves its `404.html` for every address under
https://jonnystokes.github.io/Cool-tools/, and that page sends the browser to the same page under /cooltools/ (with
its `?…` and `#…`). `index.html` is the same page, for the bare address.

The tools themselves: https://github.com/jonnystokes/cooltools

`Projects\WEB-APP-CONVENTIONS.md`, section 6.
