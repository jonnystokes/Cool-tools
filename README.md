# Cool tools

Browser tools by Jon Stokes. Each one is a single web page: open it and it runs, nothing to install.

| Tool | Open it | What it is |
|---|---|---|
| HYPERWAVE Studio | https://jonnystokes.github.io/Cool-tools/hyperwave/ | A studio of sound-reactive visuals: 63 shapes (4D wireframes and solids, fractals, clouds, solid 3D objects) that react to a microphone, PC audio, an audio file or 18 built-in demo tracks. Floating windows like a music studio: analyzer, mixer with hold-to-learn, mod matrix, scenes. |

The sound is analyzed only inside the page; nothing is sent anywhere.

The source of HYPERWAVE Studio lives in Jon's `Projects\hyperwave` folder (built with `python build.py`);
this repository holds the finished pages.
