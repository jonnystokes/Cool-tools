# Screen Peek

Hello-world test: shows a live screenshot of Jon's PC on this page (single or continuous), through
Tailscale Funnel. It works only while the Screen Peek tray app on the PC is switched ON, and only on a
phone paired once with the tray's QR code. Source and instructions: Jon's `Projects\screen-peek` folder.

Open it: https://jonnystokes.github.io/Cool-tools/screen-peek/
